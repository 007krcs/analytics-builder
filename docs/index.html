What's included

Everything you need for analytics

Six focused packages that compose into a complete analytics experience. Open-core with enterprise plugins built on the GridStorm platform.

⊞

Pivot Builder

Drag dimensions into rows and columns. Aggregate with sum, avg, count, median, stdDev, and variance. Grand totals and sub-totals included. Powered by @analytix/pivot-engine.

📊

20+ Chart Types

Bar, line, area, scatter, bubble, heatmap, treemap, funnel, waterfall, radar, sankey, candlestick, histogram, violin, and more. All rendered via Recharts 2 through @analytix/chart-engine.

📈

KPI Dashboard

Threshold-based status (good / warning / critical), period-over-period trend arrows, and auto-refresh on configurable intervals. Managed by @analytix/kpi-engine.

📄

Scheduled Reports

Compose reports with a fluent builder API. Schedule via interval, cron expression, or one-time. Export to PDF or Excel. Built with @analytix/report-builder.

🎯

No SQL Required

Load any JSON or CSV dataset and start exploring immediately. Filter, group, aggregate, and chart entirely in the browser using the in-memory AnalyticsEngine.

⚡

GridStorm Powered

Built on top of GridStorm's headless core engine — virtual scrolling, plugin system, and command bus architecture. Renders hundreds of thousands of rows smoothly.

Quick start

Up and running in 3 minutes

1

Install packages

Add the React adapter and core engine to your project.

2

Create an engine

Instantiate AnalyticsEngine and load your dataset.

3

Render the builder

Drop <AnalyticsBuilder> anywhere in your React tree.

4

Drag and explore

Drag fields into pivot zones, pick chart types, set KPI thresholds.

tsx App.tsx 
import { AnalyticsEngine } from '@analytix/core';
import {
  AnalyticsBuilder,
  useAnalyticsEngine
} from '@analytix/react';

export default function App() {
  const { engine, loadDataset } = useAnalyticsEngine();

  useEffect(() => {
    loadDataset('sales', 'Sales Data', rows);
  }, []);

  return <AnalyticsBuilder engine={engine} />;
}
