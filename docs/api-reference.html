API Reference

Complete reference for all six Analytix packages — classes, methods, types, and React component props.

@analytix/core Core engine, types, and dataset management
AnalyticsEngine
Central orchestrator. Manages datasets, computes aggregations, and provides the shared state surface for all other packages. Instantiate directly or via the useAnalyticsEngine() React hook.
new AnalyticsEngine(config?: EngineConfig) sync
Creates a new engine instance. All parameters are optional. EngineConfig accepts maxDatasets (default 10) and workerEnabled (default false — browser worker for large aggregations).
engine.loadDataset(id, label, rows) sync
Registers a dataset. id is a unique string key. rows is Row[] (any array of plain objects). Column types are inferred automatically. Throws if id is already registered — use replaceDataset() to overwrite.
engine.getDataset(id): Dataset | undefined getter
Returns the registered Dataset object or undefined if not found. Dataset exposes id, label, columns, rows, and rowCount.
engine.replaceDataset(id, label, rows) sync
Replaces an existing dataset in-place, firing all registered change listeners. Safe to call repeatedly for live-data scenarios.
engine.listDatasets(): Dataset[] getter
Returns all registered datasets in registration order.
engine.aggregate(datasetId, columnId, fn): number sync
Computes a scalar aggregate over a column. fn is one of: 'sum', 'avg', 'count', 'min', 'max', 'median', 'stddev', 'variance', 'countDistinct'.
engine.destroy(): void sync
Cleans up all datasets, listeners, and any background workers. Call in component useEffect cleanup if you create the engine manually.

@analytix/pivot-engine Pivot table computation — grouping, aggregation, totals
computePivot
Pure function that takes an engine + config and returns a PivotResult. Called internally by usePivot() but available for imperative use.
computePivot(engine, config): PivotResult sync
Computes the full pivot matrix. Returns a PivotResult containing rows, columnKeys, grandTotals, and durationMs. Throws if the dataset is not registered.

@analytix/chart-engine 26 chart type registry + config serialisation
ChartRegistry
Manages the available chart types. Each chart type has a unique id, a label, an icon, required/optional field roles (x-axis, y-axis, colour, size, etc.), and a renderer function.
ChartRegistry.getAll(): ChartTypeDef[] getter
Returns all 26 registered chart type definitions.
ChartRegistry.get(id): ChartTypeDef getter
Returns a specific chart type definition by ID.
ChartRegistry.buildConfig(typeId, fields): ChartConfig sync
Creates a ChartConfig for the given type and field mappings. Validates required field roles and throws descriptive errors if requirements are not met.

@analytix/kpi-engine KPI computation, thresholds, and auto-refresh scheduling
computeKpi
Pure function. Computes a KpiResult from an engine and a KpiConfig. Used internally by useKpi().
computeKpi(engine, config): KpiResult sync
Returns { value, status, formattedValue, trend?, progress? }. status is 'good' | 'warning' | 'critical' | 'neutral' based on the threshold configuration.
RefreshScheduler
Manages periodic re-computation of KPI values. Automatically pauses when the browser tab is hidden (if pauseWhenHidden is true).
new RefreshScheduler(engine, config, callback) sync
Creates a scheduler. callback is called with the new KpiResult on every refresh tick.
scheduler.start(): void sync
Begins the refresh interval. Safe to call multiple times — no-ops if already running.
scheduler.stop(): void sync
Stops the refresh interval and clears visibility listeners.

@analytix/report-builder Fluent API for composing and scheduling PDF/Excel reports
ReportBuilder
Fluent builder for composing multi-section reports. Chain methods to add pivot tables, KPI summaries, charts, and text sections, then call build() to get a serialisable ReportDefinition.
ReportBuilder.create(name): ReportBuilder sync
Static factory. Creates a new builder with the given report name.
.addPivot(config: PivotConfig): this sync
Appends a pivot table section to the report.
.addChart(config: ChartConfig): this sync
Appends a chart section.
.addKpiSummary(configs: KpiConfig[]): this sync
Appends a row of KPI cards as a summary section.
.addText(heading, body): this sync
Appends a free-text section.
.schedule(options: ScheduleOptions): this sync
Attaches a delivery schedule. ScheduleOptions accepts type ('interval' | 'cron' | 'once'), interval (ms for interval type), cron (cron expression string), formats (('pdf' | 'excel')[]), and enabled.
.build(): ReportDefinition sync
Finalises and returns the ReportDefinition. Validates that at least one section has been added. The definition is a plain serialisable object.
@analytix/react React components and hooks — the primary integration surface
AnalyticsBuilder
Full drag-and-drop analytics canvas. Includes field panel, pivot builder, chart builder, KPI workspace, and report scheduler — all in one component.

KpiCard
Displays a single KPI with value, status indicator, trend arrow, and progress bar. Left border colour reflects status (green/yellow/red).

Renders any chart type from a ChartConfig. Wraps Recharts under the hood with a unified responsive container and theme.

React Hooks
All hooks exported from @analytix/react.
HookReturnsDescription
useAnalyticsEngine() { engine, loadDataset, replaceDataset, version } Creates and memoizes an AnalyticsEngine instance for the component tree. Calls engine.destroy() on unmount.
usePivot(engine, config) { result, loading, error } Reactively computes a pivot table. Re-computes when config changes (deep equality). Returns loading: true while computing asynchronously.
useKpi(engine, config) { result, loading, error, refresh } Computes a KPI value and sets up auto-refresh if refreshPolicy.enabled is true. refresh() triggers an immediate re-computation.
useDatasets(engine) Dataset[] Returns all registered datasets, updating whenever a dataset is added or replaced.
useChartTypes() ChartTypeDef[] Returns all available chart types from ChartRegistry. Stable reference — never triggers re-renders.
