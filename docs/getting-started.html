Getting Started

Set up Analytix in your React application in under 5 minutes. This guide covers installation, loading a dataset, building your first pivot table, and creating a KPI dashboard.

ℹ
Prerequisites
Analytix requires React 18+, Node.js 18+, and TypeScript 5.x. We use pnpm as the package manager in all examples, but npm and yarn work too.

Installation

Install the React adapter and core engine. The other packages are peer dependencies that you only need when you want to use specific features.

pnpm add @analytix/react @analytix/core

To unlock pivot tables, charts, KPI dashboards, and reports, install the full suite:

shell 
pnpm add \
  @analytix/react \
  @analytix/core \
  @analytix/pivot-engine \
  @analytix/chart-engine \
  @analytix/kpi-engine \
  @analytix/report-builder

Peer dependencies you'll need in your project:

  • react and react-dom — version 18 or higher
  • recharts — version 2.x, for chart rendering
  • @dnd-kit/core and @dnd-kit/sortable — for drag-and-drop
pnpm add recharts @dnd-kit/core @dnd-kit/sortable

TypeScript configuration

All Analytix packages ship with TypeScript declarations. No @types packages are needed. Make sure your tsconfig.json targets ES2020 or later:

json tsconfig.json 
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "jsx": "react-jsx"
  }
}

Basic Setup

The entry point for Analytix is the AnalyticsEngine, a singleton that manages datasets, computes pivots, evaluates KPIs, and dispatches commands. The useAnalyticsEngine() hook creates and memoizes one for you inside React.

tsx App.tsx 
import React, { useEffect } from 'react';
import { AnalyticsBuilder, useAnalyticsEngine } from '@analytix/react';
import { salesData } from './data';

export default function App() {
  // Creates and memoizes an AnalyticsEngine instance
  const { engine, loadDataset } = useAnalyticsEngine();

  useEffect(() => {
    loadDataset('sales', 'Sales Data', salesData);
  }, []);

  return (
    <AnalyticsBuilder
      engine={engine}
      onExport={(fmt) => console.log('export', fmt)}
    />
  );
}
✓
Provider not required
Unlike many React libraries, Analytix does not require a context provider at the root of your application. Each useAnalyticsEngine() call creates its own isolated engine instance.

Loading a Dataset

A dataset is an array of plain JavaScript objects (rows). Every object should have consistent keys — these become the column definitions. Analytix infers column types automatically (number, string, date, boolean).

ts data.ts 
// Any array of plain objects works as a dataset.
export const salesData = [
  {
    date: '2025-01-15',
    region: 'North America',
    category: 'Software',
    revenue: 48500,
    units: 97,
    profit_margin: 0.42,
  },
  // … more rows
];

Call loadDataset(id, label, rows) to register a dataset with the engine. You can register multiple datasets and the user can switch between them in the toolbar.

ts 
// loadDataset(id, label, rows)
loadDataset('sales',     'Sales Data',    salesRows);
loadDataset('employees', 'Employee Data', employeeRows);

// Or load from an async source:
const rows = await fetch('/api/sales').then(r => r.json());
loadDataset('api-sales', 'Live Sales', rows);
⚠
Large datasets
Analytix processes data in-memory in the browser. For datasets larger than ~500k rows, consider pre-aggregating server-side and loading only the summary data. The engine performs well up to ~100k rows for interactive use.

Building Your First Pivot Table

The simplest way to build a pivot table is through the drag-and-drop AnalyticsBuilder UI. But you can also configure one programmatically using the PivotConfig type and render it with PivotTable.

// Drop <AnalyticsBuilder /> and use the Pivot tab.
// Drag region to Rows, category to Columns,
// and revenue to Values. Done.

import { AnalyticsBuilder } from '@analytix/react';

<AnalyticsBuilder engine={engine} />
import type { PivotConfig } from '@analytix/core';

const pivotConfig: PivotConfig = {
  id:          'revenue-by-region',
  datasetId:   'sales',
  rowFields:   ['region'],
  columnFields: ['category'],
  valueFields: [{
    columnId:    'revenue',
    aggregation: 'sum',
    label:       'Revenue ($)',
    format:      'currency',
  }],
  filters:          [],
  showRowTotals:     true,
  showColumnTotals:  true,
};
import { usePivot, PivotTable } from '@analytix/react';

function MyPivot({ engine }) {
  const { result, loading, error } =
    usePivot(engine, pivotConfig);

  if (loading) return <div>Computing…</div>;
  if (error)   return <div>Error: {error.message}</div>;
  if (!result)  return null;

  return <PivotTable result={result} />;
}

Creating a KPI Dashboard

KPI cards show a single aggregate metric with threshold-based status colouring (good / warning / critical). Configure them with a KpiConfig object and render with KpiCard.

tsx KpiDashboard.tsx 
import { KpiCard, useKpi } from '@analytix/react';
import type { KpiConfig } from '@analytix/core';

const revenueKpi: KpiConfig = {
  id:          'kpi-revenue',
  title:       'Total Revenue',
  datasetId:   'sales',
  columnId:    'revenue',
  aggregation: 'sum',
  format:      'currency',
  prefix:      '$',
  filters:     [],
  threshold: {
    warning:        800_000,   // yellow below this
    critical:       600_000,   // red below this
    target:         1_000_000,  // shown as target line
    comparisonType: 'greater_is_better',
  },
  refreshPolicy: {
    enabled:          true,
    intervalSeconds:  30,
    pauseWhenHidden:  true,
  },
};

function KpiDashboard({ engine }) {
  const { result } = useKpi(engine, revenueKpi);

  return (
    <div style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)' }}>
      <KpiCard
        config={revenueKpi}
        result={result}
        size="medium"
        variant="default"
      />
    </div>
  );
}
